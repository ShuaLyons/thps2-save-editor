Memory Card

THPS2 save editor

Edit careers on a Tony Hawk's Pro Skater 2 memory card (PlayStation, US version).

Memory card

Open your memory card

Choose the memory card file from your emulator's memory card folder. Files ending in .mcd, .mcr, .mc, .srm and .gme all work.

Read first

Before you start

  • This works with the US version of the game (SLUS-01066), including the Greatest Hits release.
  • Keep a copy of your memory card file before editing.
  • Save your career to the memory card in the game first. Emulator save states aren't read here, and loading an old save state can overwrite your edited card.
  • Don't use edited saves for RetroAchievements or competitive runs.
  • Everything happens in your browser. Your file isn't uploaded anywhere.

Save format research: the THPS2 demo decompilation by emoluvjd2 (memory card layout), DCxDemo's THPS2 Cumulative Patch (career data notes), community GameShark code lists, and StrategyWiki (goal lists and level requirements). The layout was confirmed against real saves in DuckStation.
